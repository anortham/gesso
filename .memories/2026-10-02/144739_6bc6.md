## Defaults and setup feedback regressions

- **WHAT:** Added editor failure and excess-argument regressions plus a Node harness that evaluates the actual Defaults, Install, and Agents QML functions.
- **WHY:** Editor persistence must follow a successful xdg-mime call; setup failures need visible messages and controls must stay disabled while synchronous refreshes run.
- **HOW:** The first shell fixture treated any nonzero editor command as an xdg-mime failure. Evidence showed the editor was absent, so package installation failed first. The fixture now provides the editor binary and asserts the xdg-mime stub was invoked before checking state.
- **IMPACT:** Focused tests now fail at the intended boundary and pass after the fixes. Node checks are skipped on systems without Node; CLI regressions still run.
