## WHY

The user approved bundling agent instructions for desktop customization, inspired by Omarchy. Repository AGENTS.md did not teach installed-system agents how to use Gesso safely.

## HOW

Use per-user symlinks to the packaged skill: shared `.agents/skills` for seven agents, dedicated Claude, Antigravity CLI, and active Oh My Pi native directories. Honor Claude and OMP configuration/profile precedence; preserve existing same-named files and foreign links. Removal unlinks only this install's exact targets, including dangling links. No RPM home scriptlets, provider calls, forced overwrites, or new dependencies. Ori has no independently documented global discovery root, so document an explicit read-the-packaged-skill prompt instead. AGENTS.md now permits these narrow discovery-path exceptions.
