## WHAT
Compared the October 2 Omarchy checkout (quattro, 821ae589) with Gesso's September baseline and completed a bounded polish pass on polish/omarchy-october. Added four mise catalog agents, native agent install preservation, literal prompt forwarding, wallpaper browsing, VS Code preflight before desktop apply, editor failure state preservation, CLI argument checks, and Setup busy/error fixes. Details and primary references are in docs/omarchy-review-2026-10-02.md.

## WHY
Bring over useful upstream last-mile behavior while keeping Gesso a Fedora KDE command pack and one Setup window. The audit proved validation order, saved-default state, hidden error, refresh reentry, native install, and relative PATH launch defects.

## HOW
Used independent workers with separate ownership and failing regression checks; the lead reviewed changes and ran the integrated suite. Native agent lookup excludes mise shim directories and makes relative executable paths absolute before the Work cwd switch. New VS Code backups remain temporary until publication. Node's built-in assertion/VM modules test actual QML JavaScript functions; test/all and CI include this check. Current registry tool IDs are documented; mise 2026.8 lacks Cursor/Ori aliases. Local Cursor, agy, omp help and checksum-verified official Ori release help confirmed launch flags. No paid sessions were launched.
