# Phase 4 agents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs. This plan is a new-session handoff; do not start until the user approves this file.

**Goal:** `gesso default agent grok` installs with stubbed `mise` and stores the id. `gesso agent` launches that agent with catalog flags. The Setup Agents page calls the same commands.

**Architecture:** `data/agents.toml` is the only mise/launch table. Hidden `gesso-agent-get` reads it. `gesso-default-agent` writes `~/.config/gesso/defaults/agent`. `gesso-agent` execs `launch` (or prints it when `GESSO_AGENT_DRY_RUN=1`). QML does not hard-code ids.

**Tech Stack:** bash 5, Python 3 `tomllib`, TAP bash tests, PATH stub for `mise`.

**Architecture Quality:**

- **Affected modules:** agent catalog, default-agent, agent launch, AgentsPage.qml, agent-test suite.
- **Caller-facing interface:** `gesso default agent [id]`, `gesso agent`.
- **Depth/locality check:** Flags live in TOML. Launch does not `case` on id.
- **Test surface:** `./test/cli` → `test/cli.d/agent-test.sh` plus setup grep.
- **Seams/adapters:** `data/agents.toml`. `mise` stubbed.
- **Rejected shortcuts:** Bash skip-prompt `case`. Hard-coded Grok in QML. Real mise in CI.
- **Architecture risk:** medium if launch flags are copied into QML or a case.

## Global Constraints

- Spec: `plans/2026-08-27-phase-4-agents-design.md`.
- Default path: `$HOME/.config/gesso/defaults/agent`.
- Dry-run: `GESSO_AGENT_DRY_RUN=1` prints `cwd=` and `argv=` and does not exec.
- Work dir: if `$PWD` == `$HOME` and `$HOME/Work` is a directory, cd there before launch.
- Skip mise when `launch[0]` is already on PATH; still write the default file.
- QML must not contain `npm:@xai-official` or other mise specs.
- `# gesso:summary=` on new `bin/gesso-*`. Two-space indent. `#!/bin/bash`.
- No `gesso-agents` RPM in this phase.

[[ $cur == "unset" ]] || fail "no default agent is unset" "$cur"

if gesso default agent --help >/dev/null 2>&1; then
  :
else
  fail "gesso default agent --help exits 0"
fi

  fail "unknown default agent exits non-zero"
