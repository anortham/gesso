**Worker ceiling:** the owned suite file. Workers in a parallel batch do not run `./test/cli` because sibling edits are in flight.

**Worker gate invariant:** the owned suite prints only `ok -` lines and exits 0.

**Lead affected-change scope:** `./test/all` after each batch commit.

**Branch gate:** `./test/all`, plus a Setup build in a `registry.fedoraproject.org/fedora:44` podman container with the CI job's package list.

**Security scope:** none declared

**Replay/metric evidence:** none

**Escalation triggers:** none. Do not run `rpmbuild` or a Plasma session.

**Assigned verification failure:** Stop. Do not weaken assertions.

**Verification ledger:** Record command, HEAD, result after each commit.

TDD: failing test first for each new behavior.

Commit mode: `parallel-lead-commit` for Batch A. `serial-worker-commit` for Task 7.
