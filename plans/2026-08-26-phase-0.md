# Phase 0 CLI skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs. This plan is a new-session handoff; do not start until the user opens this repo and asks to implement it.

**Goal:** A checkout can run `./bin/gesso theme list` and `./test/all` with no Plasma session, listing the first-party `tokyo-night` theme.

**Architecture:** `bin/gesso` is a longest-prefix filename router onto `bin/gesso-*`. Data lives under `$GESSO_PATH`. Tests export a fake `$HOME` and the repo as `$GESSO_PATH`. No Setup app, no theme apply, no dnf.

**Tech Stack:** bash 5, TAP-flavored bash tests, one `colors.toml`.

**Architecture Quality:**

- **Affected modules:** CLI router, theme list command, test harness.
- **Caller-facing interface:** `gesso`, `gesso --help`, `gesso theme list`, `gesso commands` (text).
- **Depth/locality check:** All behavior is in `bin/` and `./test/cli`. No Plasma, no QML.
- **Test surface:** `./test/cli` invokes the same `bin/gesso` a user will run.
- **Seams/adapters:** `$GESSO_PATH` and `$HOME` only.
- **Rejected shortcuts:** Do not copy `bin/omarchy`. Do not add a command registry file. Do not apply themes in this phase.
- **Architecture risk:** low if the router stays filename-based; medium if metadata loading is built before a second command needs it. Phase 0 uses filename fast path only.

## Global Constraints

- Commands are `gesso-*` under `bin/`. Shebang `#!/bin/bash`.
- Metadata keys use `# gesso:summary=` (not `omarchy:`).
- `$GESSO_PATH` is required for data. Unset + git checkout with `themes/` next to `bin/` → repo root. Else `/usr/share/gesso`.
- Two-space indent, `[[ ]]` / `(( ))` as in `AGENTS.md`.
- No `/etc`, no Hyprland, no QML, no RPM spec in this phase.
- First theme directory name: `tokyo-night`. List output is that directory name, one per line, sorted.
- User themes, if present under `$HOME/.config/gesso/themes/<name>/colors.toml`, appear in the list. Duplicate names (shipped + user) print once.
- `./test/cli` and `./test/all` must pass without DBus, Plasma, or network.

`bin/gesso`:

```bash
#!/bin/bash
set -euo pipefail

GESSO_BIN_DIR=$(cd -- "$(dirname -- "${BASH_SOURCE[0]}")" && pwd)
GESSO_ROOT=$(cd -- "$GESSO_BIN_DIR/.." && pwd)

if [[ -z ${GESSO_PATH:-} ]]; then
  if [[ -d $GESSO_ROOT/themes ]]; then
    export GESSO_PATH=$GESSO_ROOT
  else
    export GESSO_PATH=/usr/share/gesso
  fi
fi

export PATH="$GESSO_BIN_DIR:$PATH"

usage() {
  cat <<'EOF'
Usage: gesso <command> [args]

Commands:
  theme list    List available themes
  commands      List commands

Use gesso <command> --help for a command's usage.
EOF
}

if (($# == 0)) || [[ $1 == "--help" || $1 == "-h" ]]; then
  usage
  exit 0
fi

if [[ $1 == "commands" ]]; then
  usage
  exit 0
fi

join_hyphen() {
  local joined="$1"
  shift
  local word
  for word in "$@"; do
    joined+="-$word"
  done
  printf '%s' "$joined"
}

words=("$@")
i=${#words[@]}
found=""
leftover=()

while ((i >= 1)); do
  probe="gesso-$(join_hyphen "${words[@]:0:i}")"
  if [[ -x $GESSO_BIN_DIR/$probe ]]; then
    found=$probe
    leftover=("${words[@]:i}")
    break
  fi
  ((i--)) || true
done

if [[ -z $found ]]; then
  printf 'Unknown command: gesso %s\n' "$*" >&2
  usage >&2
  exit 1
fi

for arg in "${leftover[@]+"${leftover[@]}"}"; do
  if [[ $arg == "--help" || $arg == "-h" ]]; then
    # Phase 0: exec the command with no args if it is help; commands with
    # required args will print usage. theme-list has no required args, so
    # also print usage here when leftover is only the help flag.
    exec "$GESSO_BIN_DIR/$found" --help
  fi
done

exec "$GESSO_BIN_DIR/$found" "${leftover[@]+"${leftover[@]}"}"
```

`bin/gesso-theme-list`:

```bash
#!/bin/bash
# gesso:summary=List available Gesso themes
# gesso:args=

set -euo pipefail

if [[ ${1:-} == "--help" || ${1:-} == "-h" ]]; then
  printf 'Usage: gesso theme list\n'
  exit 0
fi

if [[ -z ${GESSO_PATH:-} ]]; then
  printf 'GESSO_PATH is not set\n' >&2
  exit 1
fi

declare -A seen=()
names=()

collect() {
  local dir=$1
  local path name
  [[ -d $dir ]] || return 0
  for path in "$dir"/*/colors.toml; do
    [[ -f $path ]] || continue
    name=$(basename "$(dirname "$path")")
    if [[ -z ${seen[$name]+x} ]]; then
      seen[$name]=1
      names+=("$name")
    fi
  done
}

collect "$GESSO_PATH/themes"
collect "$HOME/.config/gesso/themes"

if ((${#names[@]} == 0)); then
  exit 0
fi

printf '%s\n' "${names[@]}" | sort
```
