# Phase 1 theme engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs. This plan is a new-session handoff; do not start until the user approves this file.

**Goal:** `gesso theme set tokyo-night` stages a theme, renders templates, writes Plasma and Konsole files, and stays green under `./test/all` with no Plasma session.

**Architecture:** `bin/gesso-theme-set` orchestrates lock, stage, overlay, swap, live copies, session apply, and hooks. `bin/gesso-theme-set-templates` (hidden) renders `{{ }}` placeholders into `next-theme`. App file shapes live in `default/themed/*.tpl`. Tests call `gesso theme set` only.

**Tech Stack:** bash 5, TAP-flavored bash tests, `colors.toml` plus `*.tpl`, stub `plasma-apply-colorscheme` and `gsettings`.

**Architecture Quality:**

- **Affected modules:** CLI theme-set, hidden template renderer, `default/themed/*.tpl`, test harness split.
- **Caller-facing interface:** `gesso theme set <name>`, `gesso theme set --help`.
- **Depth/locality check:** Orchestration in `theme-set`. Placeholder math in `theme-set-templates`. File shapes in templates.
- **Test surface:** `./test/cli` runs `test/cli.d/*-test.sh`. Theme tests invoke `gesso theme set`.
- **Seams/adapters:** `colors.toml` plus templates. Plasma/GTK behind `GESSO_THEME_HEADLESS` and PATH stubs.
- **Rejected shortcuts:** Vendoring Omarchy files. Full TOML parser. Rewriting `kitty.conf` or VS Code `settings.json`. Live Plasma in tests.
- **Architecture risk:** medium if retints sprawl. Keep apply in one command.

## Global Constraints

- Theme names are directory names (`tokyo-night`), the same strings `gesso theme list` prints.
- `$GESSO_PATH` is the data root. Commands must use it.
- Write under `$HOME` only: `~/.local/state/gesso`, `~/.local/share`, `~/.config`. Never `/etc`.
- `GESSO_THEME_HEADLESS=1` skips Plasma, GTK, and retints. Staging and generation still run.
- Shebang `#!/bin/bash`. Two-space indent. `[[ ]]` / `(( ))` as in `AGENTS.md`.
- `# gesso:summary=` in the first 80 comment lines of every `bin/gesso-*`.
- Hidden helper: `# gesso:hidden=true` on `bin/gesso-theme-set-templates`.
- `# gesso:args=<name>` on `bin/gesso-theme-set`. No args prints usage, exit 1.
- Do not copy Omarchy trees. Steal the stage-render-swap loop only.
- No wallpaper, `theme install`, extra palettes, Setup app, or Ghostty/Foot.
- Spec: `plans/2026-08-26-phase-1-theme-engine-design.md`.

`bin/gesso-theme-set-templates`:

```bash
#!/bin/bash
# gesso:summary=Render Gesso theme templates
# gesso:hidden=true

set -euo pipefail

NEXT=${GESSO_NEXT_THEME:-$HOME/.local/state/gesso/current/next-theme}
COLORS=$NEXT/colors.toml
declare -A THEME_COLORS=()

hex_to_rgb() {
  local hex=${1#\#}
  printf '%d,%d,%d' "0x${hex:0:2}" "0x${hex:2:2}" "0x${hex:4:2}"
}

mix_color() {
  local start=${1#\#}
  local end=${2#\#}
  local amount=$3
  awk -v start="$start" -v end="$end" -v amount="$amount" '
    function hv(c) { return index("0123456789abcdef", tolower(c)) - 1 }
    function pair(h, i) { return hv(substr(h, i, 1)) * 16 + hv(substr(h, i + 1, 1)) }
    BEGIN {
      if (amount ~ /%$/) { sub(/%$/, "", amount); amount = amount / 100 }
      else { amount += 0; if (amount > 1) amount = amount / 100 }
      if (amount < 0) amount = 0
      if (amount > 1) amount = 1
      r = int(pair(start, 1) * (1 - amount) + pair(end, 1) * amount + 0.5)
      g = int(pair(start, 3) * (1 - amount) + pair(end, 3) * amount + 0.5)
      b = int(pair(start, 5) * (1 - amount) + pair(end, 5) * amount + 0.5)
      printf "#%02x%02x%02x\n", r, g, b
    }
  '
}

[[ -f $COLORS ]] || { printf 'colors.toml missing after overlay\n' >&2; exit 1; }

while IFS= read -r line || [[ -n $line ]]; do
  [[ $line =~ ^[[:space:]]*# ]] && continue
  [[ $line =~ ^[[:space:]]*$ ]] && continue
  if [[ $line =~ ^([A-Za-z0-9_]+)[[:space:]]*=[[:space:]]*\"([^\"]+)\" ]]; then
    THEME_COLORS[${BASH_REMATCH[1]}]=${BASH_REMATCH[2]}
  fi
done <"$COLORS"

if [[ -n ${THEME_COLORS[background]+x} && -z ${THEME_COLORS[bg]+x} ]]; then
  THEME_COLORS[bg]=${THEME_COLORS[background]}
fi
if [[ -n ${THEME_COLORS[bg]+x} && -z ${THEME_COLORS[background]+x} ]]; then
  THEME_COLORS[background]=${THEME_COLORS[bg]}
fi
if [[ -n ${THEME_COLORS[foreground]+x} && -z ${THEME_COLORS[fg]+x} ]]; then
  THEME_COLORS[fg]=${THEME_COLORS[foreground]}
fi
if [[ -n ${THEME_COLORS[fg]+x} && -z ${THEME_COLORS[foreground]+x} ]]; then
  THEME_COLORS[foreground]=${THEME_COLORS[fg]}
fi
if [[ -n ${THEME_COLORS[selection]+x} ]]; then
  THEME_COLORS[selection_background]=${THEME_COLORS[selection]}
fi
if [[ -n ${THEME_COLORS[bright_foreground]+x} ]]; then
  THEME_COLORS[selection_foreground]=${THEME_COLORS[bright_foreground]}
fi

render_file() {
  local tpl=$1
  local out=$2
  local content key val
  content=$(cat "$tpl")
  while [[ $content =~ \{\{[[:space:]]*mix[[:space:]]+([A-Za-z0-9_]+)[[:space:]]+([A-Za-z0-9_]+)[[:space:]]+([^}]+)[[:space:]]*\}\} ]]; do
    val=$(mix_color "${THEME_COLORS[${BASH_REMATCH[1]}]}" "${THEME_COLORS[${BASH_REMATCH[2]}]}" "$(echo "${BASH_REMATCH[3]}" | tr -d '[:space:]')")
    content=${content/${BASH_REMATCH[0]}/$val}
  done
  for key in "${!THEME_COLORS[@]}"; do
    val=${THEME_COLORS[$key]}
    content=${content//"{{ $key }}"/$val}
    content=${content//"{{ ${key}_strip }}"/${val#\#}}
    content=${content//"{{ ${key}_rgb }}"/$(hex_to_rgb "$val")}
  done
  printf '%s' "$content" >"$out"
  if [[ $content != *$'\n' ]]; then
    :
  fi
}

render_dir() {
  local dir=$1
  local tpl base out
  [[ -d $dir ]] || return 0
  for tpl in "$dir"/*.tpl; do
    [[ -f $tpl ]] || continue
    base=$(basename "$tpl" .tpl)
    out=$NEXT/$base
    if [[ -e $out ]]; then
      continue
    fi
    render_file "$tpl" "$out"
  done
}

render_dir "${HOME}/.config/gesso/themed"
render_dir "${GESSO_PATH}/default/themed"
```

Canonical names already in the file win because we only fill legacy keys when missing. `background` present means we do not let a later `bg` overwrite it if we fill `bg` from `background` only when `bg` is empty. Parser order: file keys first (user overlay already merged into `colors.toml` on disk), then derived.

Call the helper from `bin/gesso-theme-set` after overlay and before swap:

```bash

```
