# Phase 2 defaults Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs. This plan is a new-session handoff; do not start until the user approves this file.

**Goal:** `gesso default browser firefox` installs Firefox when missing (stubbed `dnf`) and `xdg-settings` reports `firefox.desktop`. Terminal and editor defaults use the same catalog.

**Architecture:** `data/apps.toml` is the only package list. Hidden `gesso-catalog-get` reads it with Python `tomllib`. `gesso pkg add` installs. `gesso default browser|terminal|editor` checks present, maybe installs, then sets the handler. Tests call those user commands.

**Tech Stack:** bash 5, Python 3 `tomllib`, TAP-flavored bash tests, PATH stubs for `dnf` / `flatpak` / `sudo` / `xdg-settings`.

**Architecture Quality:**

- **Affected modules:** catalog, pkg add, default browser/terminal/editor, default-test suite.
- **Caller-facing interface:** `gesso default browser [id]`, `gesso default terminal [id]`, `gesso default editor [id]`, `gesso pkg add <id>`.
- **Depth/locality check:** Parse in catalog-get. Privilege in pkg-add. Default commands do not talk to dnf directly.
- **Test surface:** `./test/cli` → `test/cli.d/default-test.sh` plus existing suites.
- **Seams/adapters:** `data/apps.toml`. Package tools and `xdg-settings` are stubs.
- **Rejected shortcuts:** Hard-coded `case` of browsers. Real `dnf` in tests.
- **Architecture risk:** medium if stubs fail to shadow real `dnf`. Stubs must be first on PATH.

## Global Constraints

- Catalog path is `$GESSO_PATH/data/apps.toml`. Do not hard-code package names in default commands.
- Theme names and theme engine stay unchanged.
- Stub `dnf`, `flatpak`, `pkexec`, `sudo`. Never a real RPM transaction.
- Privilege: EUID 0 runs the tool; TTY uses `sudo`; else `pkexec`. `sudo` stubs exec the rest of argv.
- `# gesso:summary=` on every `bin/gesso-*`. Hidden helpers set `# gesso:hidden=true`.
- Shebang `#!/bin/bash`. Two-space indent. AGENTS.md `[[ ]]` rules.
- Spec: `plans/2026-08-27-phase-2-defaults-design.md`.
- No `pkg drop`, agents, extra kind, or Setup app.

`bin/gesso-catalog-get`:

```bash
#!/bin/bash
# gesso:summary=Read a field from the app catalog
# gesso:hidden=true
# gesso:args=<id> <field>|--kind <kind>

set -euo pipefail

if [[ ${1:-} == "--help" || ${1:-} == "-h" ]]; then
  printf 'Usage: gesso-catalog-get <id> <field>\n'
  printf '       gesso-catalog-get --kind <kind>\n'
  exit 0
fi

if [[ -z ${GESSO_PATH:-} ]]; then
  printf 'GESSO_PATH is not set\n' >&2
  exit 1
fi

catalog=$GESSO_PATH/data/apps.toml
if [[ ! -f $catalog ]]; then
  printf 'catalog not found: %s\n' "$catalog" >&2
  exit 1
fi

python3 - "$catalog" "$@" <<'PY'
import sys
import tomllib
from pathlib import Path

catalog = Path(sys.argv[1])
args = sys.argv[2:]
data = tomllib.loads(catalog.read_text())
apps = data.get("app") or []

if len(args) == 2 and args[0] == "--kind":
    kind = args[1]
    ids = [a["id"] for a in apps if a.get("kind") == kind]
    if not ids:
        sys.exit(1)
    print("\n".join(ids))
    sys.exit(0)

if len(args) != 2:
    sys.stderr.write("Usage: gesso-catalog-get <id> <field>\n")
    sys.exit(1)

app_id, field = args
row = next((a for a in apps if a.get("id") == app_id), None)
if row is None:
    sys.stderr.write(f"Unknown app: {app_id}\n")
    sys.exit(1)
if field not in row:
    if field == "dnf":
        print("")
        sys.exit(0)
    if field == "flatpak":
        print("")
        sys.exit(0)
    sys.stderr.write(f"Unknown field: {field}\n")
    sys.exit(1)
value = row[field]
if isinstance(value, list):
    print(" ".join(str(v) for v in value))
else:
    print(value)
PY
```
