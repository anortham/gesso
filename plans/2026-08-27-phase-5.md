# Phase 5 packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use razorback:subagent-driven-development when subagent delegation is available. Fall back to razorback:executing-plans for single-task, tightly-sequential, or no-delegation runs. This plan is a new-session handoff; do not start until the user approves this file.

**Goal:** A Fedora 44 spec ships `gesso`, `gesso-plasma`, and `gesso-agents`. The Setup GUI lives in libexec. `gesso theme restore` can put Breeze back. `./test/all` stays green without COPR or `rpmbuild`.

**Architecture:** One `packaging/gesso.spec` with subpackages. Bash `gesso-setup` execs `/usr/libexec/gesso/gesso-setup`. Restore is a user command, not an RPM scriptlet.

**Tech Stack:** RPM spec, CMake install dest, bash, TAP tests.

**Architecture Quality:**

- **Affected modules:** spec file, launcher, CMake install, theme restore, packaging tests.
- **Caller-facing interface:** `dnf install gesso-plasma`, `gesso theme restore`.
- **Depth/locality check:** File lists only. Restore does not scan `/etc`.
- **Test surface:** `./test/cli` packaging assertions. No mock.
- **Seams/adapters:** RPM payload vs `$HOME`. COPR is human-only.
- **Rejected shortcuts:** PATH collision for `gesso-setup`. `%preun` Plasma DBus as root.
- **Architecture risk:** medium around uninstall. Restore stays a user command.

## Global Constraints

- Spec: `plans/2026-08-27-phase-5-packaging-design.md`.
- No `/etc` in the RPM. No COPR tokens. No `rpmbuild` in `./test/cli`.
- License MIT plus a `LICENSE` file.
- Fedora 44. Version `0.1.0`.
- `# gesso:summary=` on `bin/gesso-theme-restore`. Two-space indent. `#!/bin/bash`.
- Do not publish COPR from this plan.

**Step 1: Write the failing test**

```bash
[[ -f $ROOT/LICENSE ]] || fail "LICENSE exists"
[[ -f $ROOT/packaging/gesso.spec ]] || fail "gesso.spec exists"
spec=$(cat "$ROOT/packaging/gesso.spec")
[[ $spec == *"%package plasma"* ]] || fail "spec has plasma subpackage"
[[ $spec == *"%package agents"* ]] || fail "spec has agents subpackage"
[[ $spec == *"Name: gesso"* ]] || fail "spec Name is gesso"
[[ $spec == *"/etc/"* ]] && fail "spec must not ship /etc"
[[ $spec == *libexec*gesso/gesso-setup* || $spec == *"%{_libexecdir}/gesso/gesso-setup"* ]] || fail "spec installs libexec gesso-setup"
pass "spec has three packages and no /etc"
```

Adjust the libexec match to whatever the spec macro line actually is, but the test must require `%{_libexecdir}/gesso/gesso-setup` as a substring.

**Step 2: Run test to verify it fails**

Run: `./test/cli`

Expected: FAIL missing spec.

**Step 3: Write minimal implementation**

`LICENSE`: standard MIT, copyright holder Alan Northam, year 2026.

`packaging/gesso.spec`:

- `Name: gesso`, `Version: 0.1.0`, `Release: 1%{?dist}`, `License: MIT`, `URL: https://github.com/anortham/gesso`
- `Source0` tarball or forge URL
- `BuildRequires:` cmake, extra-cmake-modules, gcc-c++, kf6-kirigami-devel, qt6-qtbase-devel, qt6-qtdeclarative-devel, qt6-qtquickcontrols2-devel
- `%build` cmake for `setup/`
- `%install` install bash scripts to `%{_bindir}`, data to `%{_datadir}/gesso`, cmake install for the GUI, desktop file to `%{_datadir}/applications`
- `%package plasma` / `%description plasma` / `%files plasma`
- `%package agents` with `Requires: gesso, mise`, `%files agents` can be empty except a `%ghost` is ugly — use `Requires` only and `%files agents` with no paths is invalid. Put a one-line `%{_datadir}/gesso/README.agents` or include `data/agents.toml` only in agents? Spec said agents scripts stay in gesso. For an empty metapackage Fedora allows:

```
%files agents
%doc
```

Better: `%files agents` contains nothing and we add `Provides: gesso-agents` with `Requires: mise` using `%package agents` and a dummy:

```
%files agents
%license LICENSE
```

Sharing LICENSE in two packages is OK with `%license`.

- `%files` (main): bindir scripts except do not put compiled GUI there; datadir gesso; LICENSE
- `%files plasma`: libexec binary, desktop file
- `%post` / `%preun`: none that call Plasma

Do not list `plans/`, `test/`, `.memories/`.
